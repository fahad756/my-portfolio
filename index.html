Signature integration

HubSpot to ServiceM8 automation built like a production workflow engine.

Public Repo FSE ServiceM8 Integration

CRM deal stages trigger field-service jobs without manual handoff.

A Flask-based webhook service that connects HubSpot CRM with ServiceM8. It receives HubSpot and ServiceM8 events, queues handlers in a background worker, creates ServiceM8 clients and jobs from HubSpot deals, prevents duplicate job creation through stored ServiceM8 IDs, and keeps quote/schedule stages synchronized back to HubSpot.

View GitHub Repo See Stack
HubSpot Deals + Contacts
ServiceM8 Clients + Jobs
Flask Queue Webhook Worker
01

Stage-gated job creation

Creates ServiceM8 jobs only when the HubSpot deal reaches the configured consult stage and does not already have an sm8_job_id.

02

CRM association handling

Reads associated HubSpot contact data, creates or reuses the ServiceM8 client, then stores ServiceM8 client/job UUIDs back in HubSpot.

03

Bidirectional status sync

Handles quote sent, quote accepted, scheduled activity, and work-order updates to keep HubSpot deal stages aligned with ServiceM8 activity.

04

Async webhook processing

Uses a background queue worker so webhook requests can return quickly while handlers process API calls and logging safely.

integration-flow.py 
POST /webhook
  -> identify object type
  -> queue handler
  -> validate HubSpot deal stage
  -> create ServiceM8 client + job + contact
  -> write sm8_client_id and sm8_job_id back to HubSpot
  -> sync quote, schedule, and work-order status changes

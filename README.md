# Fahad Waseem Portfolio

Static animated portfolio website for GitHub Pages.

## Files

- `index.html` - content, sections, project cards, CV links
- `styles.css` - visual system, responsive layout, animations
- `script.js` - canvas particles, card tilt, terminal switcher, mobile nav
- `CV - Fahad Waseem.pdf` - existing CV file, linked but not modified

## Deploy On GitHub Pages

1. Push these files to a GitHub repository.
2. Open repository `Settings`.
3. Go to `Pages`.
4. Set source to `Deploy from a branch`.
5. Select `main` branch and `/root`.
6. Save and wait for the GitHub Pages URL.

## Edit Later

Update the project cards in `index.html` under the `Featured builds` section. Replace the placeholder cards with real project links, screenshots, and metrics when ready.

About Me

I'm Fahad Waseem, a backend Python developer based in Paris, France. I specialize in building the systems that connect, move, and transform data — APIs, automation pipelines, CRM integrations, and cloud functions that run reliably in production.

Currently working at Workabot.ai, where I build Flask services and AWS Lambda functions that power enterprise data workflows — from HubSpot CRM integrations to Samsara fleet data pipelines. Before that, I was at Learners.ai building Python automation tools and REST API backends.

I care about writing clean, maintainable backend code. I prefer systems that are simple, observable, and composable over complex abstractions. When something breaks at 3am, it should be obvious why.
